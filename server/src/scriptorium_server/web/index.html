Scriptorium is a shared literature collection for the Societal Analytics Lab. It holds the publications of the journals, proceedings and preprint servers we follow, with their abstracts, and the full text of many of them. Members' agents search it to find, read and cite literature.

How it works

The server keeps the collection up to date. Each week it collects the new publications of every venue it follows, and it reads the PDFs members donate. Each publication is indexed, so it can be found by meaning as well as by exact words.

Members use Scriptorium through their own AI agent, such as Claude, with any agent that supports MCP. A small program on the member's computer, the Scriptorium client, gives the agent tools to look up, search and inspect publications, download and donate PDFs, export BibTeX, and exchange items with Zotero.

Getting started

Ask an admin for an API key, then install the client: see the client setup guide.
